# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-11-01

### Added
- Initial release of xyzen-ui component library
- Button component with multiple variants (default, secondary, destructive, outline, ghost, link)
- Button component with multiple sizes (sm, default, lg, icon)
- Card component with sub-components (CardHeader, CardTitle, CardDescription, CardContent, CardFooter)
- Input component with full accessibility support
- `cn` utility function for merging Tailwind CSS classes
- TypeScript support with full type definitions
- ESM and CommonJS build outputs
- Tailwind CSS configuration with custom theme
- Comprehensive documentation and examples
- ESLint configuration for code quality
- Example agent dashboard demonstrating component usage

### Technical Details
- Built with React 18 and TypeScript 5
- Uses Tailwind CSS 3 for styling
- Uses class-variance-authority for component variants
- Build system powered by tsup
- Supports both light and dark themes via CSS variables
- Tree-shakeable exports
